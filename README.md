# Zepto Capstone Project

This repository contains the modules for the Zepto capstone project.

## Modules

- **analytics/** - Titanic dataset EDA and predictive modeling. See analytics/README.md for details.
- **data_pipeline/** - data pipeline module. See data_pipeline/README.md for details.
- **support_assistant/** - RAG-based customer support assistant for Zepto, built with LangGraph, ChromaDB, and FastAPI. See support_assistant/README.md for details.

Each module has its own README with full setup instructions and results.
